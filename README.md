# ร้านชุมชน — สต็อกง่าย ขายไว

เว็บแอป HTML แบบง่ายสำหรับร้านขายของชำชุมชน ใช้ได้บนโทรศัพท์และคอมพิวเตอร์ โดยไม่ต้องติดตั้ง PHP, MySQL หรือ XAMPP

## ฟีเจอร์

- เพิ่มสินค้า
- ค้นหาสินค้า
- เพิ่ม/ลดจำนวนสต็อก
- เลือกสินค้าใส่บิล
- บันทึกการขาย
- ดูยอดขายวันนี้
- แจ้งสินค้าใกล้หมด/หมด
- บันทึกข้อมูลด้วย `localStorage`
- Responsive สำหรับมือถือ

## วิธีเปิดใช้งานทันที

ดับเบิลคลิกไฟล์ `index.html` หรือเปิดด้วยเบราว์เซอร์ได้เลย

## วิธีนำขึ้น GitHub Pages

1. สร้าง GitHub Repository ใหม่ เช่น `community-stock`
2. อัปโหลดไฟล์ `index.html`, `styles.css`, `app.js` และ `README.md`
3. ไปที่ **Settings → Pages**
4. ในหัวข้อ **Build and deployment** เลือก **Deploy from a branch**
5. เลือก Branch เป็น `main` และ Folder เป็น `/ (root)`
6. กด **Save**
7. รอสักครู่ แล้วเปิด URL รูปแบบ:

```text
https://ชื่อผู้ใช้.github.io/community-stock/
```

## ข้อจำกัดสำคัญ

ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น หากเปิดจากโทรศัพท์อีกเครื่องจะไม่เห็นข้อมูลเดียวกัน และหากล้างข้อมูลเว็บไซต์ ข้อมูลอาจหายได้

รุ่นนี้เหมาะสำหรับทดลองใช้หรือร้านที่ใช้เครื่องเดียว หากต้องการใช้หลายเครื่องและเก็บข้อมูลออนไลน์ ต้องเพิ่มฐานข้อมูลออนไลน์ เช่น Supabase หรือ Firebase ในรุ่นถัดไป
